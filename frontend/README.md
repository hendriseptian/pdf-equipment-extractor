# PDF Equipment Extractor — Frontend V1

Frontend-only V1 for the Cloudflare Worker backend.

Backend:
https://pdf-equipment-extractor.side-gs78.workers.dev

Features:
- Online PDF upload
- Drag and drop
- 15 MB validation
- POST PDF to `/api/analyze`
- Equipment count
- Equipment result table
- Raw JSON viewer
- API health indicator

Deploy this `frontend` folder to GitHub Pages.
